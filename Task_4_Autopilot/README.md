# Контрольная 2. Вариант 2. Task_4_Autopilot

Запуск: Windows/AutopilotLab.exe. Переносите папку Windows целиком.
Qt Creator: откройте Project/CMakeLists.txt или Project/Control_Work_02_Polymorphism.pro, выберите Desktop Qt 6, соберите и запустите цель AutopilotLab.
Интерфейс написан на Qt Widgets и QPainter в main.cpp. Форма создаётся программно; отдельного .ui нет.

Все модели отделены в .h/.cpp. Абстрактные интерфейсы имеют virtual-деструкторы; реализации используют override. Поля закрыты. Вывод модели идёт через qDebug, интерфейс также показывает журнал.

## Проверка и защита
Autopilot хранит невладеющие указатели на UAV, Sensor, NavigationSystem и FlightController. Объекты должны существовать дольше цикла. run_cycle проверяет БПЛА, все сенсоры, навигацию, координаты и регулятор, затем вычисляет error=200-altitude и output=0.5*error при dt=0.1. При высоте150 результат25.
В варианте2 нет отдельного задания на регулятор, поэтому добавлены необходимый абстрактный FlightController и SimpleController. Подключён Quadcopter и навигационный GPS-сенсор; прочие реализации демонстрируются в отдельных заданиях1–3. Во время цикла нет проверок конкретного типа.
Для пяти обязательных сценариев: штатный запуск; снять готовность сенсора; снять готовность GPS; отключить регулятор; ввести высоту−1. Дополнительно можно отключить БПЛА. Нажимайте «Выполнить проверку» после изменения. Схема показывает ошибку высоты, а не движение аппарата во времени.
tests.cpp проверяет все пять обязательных случаев и три дополнительных случая нулевых указателей. Пустой список сенсоров допустим по контракту; каждый добавленный сенсор считается критическим.

Тесты: cmake --build build; ctest --test-dir build --output-on-failure. Qt6/bin и MinGW/bin должны быть в PATH. Данные являются учебными и не поступают с реальной аппаратуры.
