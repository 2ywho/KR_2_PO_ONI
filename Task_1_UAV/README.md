# Задание 1 — БПЛА и полиморфизм

Самостоятельное приложение Qt 6 / C++17, контрольная работа № 2, вариант 2.

## Запуск
Откройте `Windows/Control_Work_02_Polymorphism.exe`. Установка Qt не нужна. Папку Windows переносите целиком.

Выберите аппарат, нажмите «Взлёт», затем «Посадка». Роторы вращаются быстрее в полёте. Состояние каждого из трёх аппаратов сохраняется при переключении. Недопустимая команда недоступна в интерфейсе и дополнительно защищена исключением в модели. Кнопка «Сведения об аппарате» выводит характеристики в журнал и через qDebug.

## Сборка
Откройте CMakeLists.txt или Control_Work_02_Polymorphism.pro в Qt Creator и выберите комплект Qt 6 MinGW. Интерфейс создан программно в src/main.cpp; файла .ui нет.

Командная сборка (Qt и MinGW должны быть в PATH):
```
cmake -S . -B build -G Ninja -DCMAKE_PREFIX_PATH=C:/Qt/6.12.0/mingw_64 -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build --output-on-failure
build/Control_Work_02_Polymorphism.exe --smoke-test
```

Параметр `--screenshot path.png` сохраняет снимок окна и завершает программу. Модельные тесты проверяют абстрактность, виртуальный деструктор, 4/6/8 двигателей, переходы состояний и исключения повторных команд. Проверка GUI переключает все модели, нажимает кнопки и проверяет их доступность и состояние модели.

Схема и вращение — учебная визуализация, не физическая модель полёта. Все аппараты взлетают и садятся вертикально; число роторов различается.
